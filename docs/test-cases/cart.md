# Cart Test Cases

**Automation:** `tests/ui/cart.spec.ts`  |  **Master CSV:** `docs/test-cases/cart.csv`  |  **Reports:** `reports/cart/Cart test <DD-MM-YYYY>_<HH-mm-ss>.html` (all runs: `reports/index.html`)
**Application:** https://automationexercise.com

## Overview
Adding products to the cart, quantities, removing products, recommended items and the cart after login.

## Scope and notes
Every test uses a fresh anonymous browser session or its own user, because the cart is stored on the server per session.
