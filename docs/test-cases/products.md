# Products Test Cases

**Automation:** `tests/ui/products.spec.ts`  |  **Master CSV:** `docs/test-cases/products.csv`  |  **Reports:** `reports/products/Products test <DD-MM-YYYY>_<HH-mm-ss>.html` (all runs: `reports/index.html`)
**Application:** https://automationexercise.com

## Overview
Product list, product details, search, categories, brands and product reviews.

## Scope and notes
Search matches the product name and its category (for example "top" also finds items of category "Tops"), so assertions use known product names. Data is read-only except for reviews.
